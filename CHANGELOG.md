# Changelog

All notable changes are documented here. Versions follow Semantic Versioning.

## [1.0.0] - 2026-08-27

### Added

- Strict v1alpha1 SLO schema with ownership and operational-link policy.
- Prometheus recording rules and four multi-window burn-rate alerts.
- Prometheus Operator and Grafana dashboard output.
- Human-readable error-budget and alert-policy explanation.
- CLI validation, rendering, explanation, HTTP service, and health probe commands.
- Non-root static container, CI validation, release automation, tests, runbook, and threat model.
