# Code of conduct

This project is committed to a welcoming, respectful, and harassment-free community.

Be constructive, assume good intent, focus criticism on the work, and respect differing experience levels and viewpoints. Harassment, discrimination, threats, doxxing, and sustained disruption are not acceptable.

Project maintainers may edit or remove contributions and restrict participation when behavior violates these expectations. Report conduct concerns privately through the repository's security reporting channel. Maintainers will review reports fairly and protect reporters' privacy where possible.
