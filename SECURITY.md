# Security policy

## Supported versions

Security fixes are provided for the latest published release.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** flow to send a private report. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Please do not open a public issue before a fix is available. You can expect an initial response within seven days. Confirmed reports will be coordinated through a patch release and security advisory.
